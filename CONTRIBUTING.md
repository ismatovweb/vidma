# Contributing

## Процесс

1. Fork
2. git checkout -b feat/my-feature
3. Изменения
4. Линтеры и тесты
5. git commit -m "feat: add my feature"
6. Push и Pull Request

## Стиль коммитов

Conventional Commits:
- feat: новая функциональность
- fix: баг
- docs: документация
- refactor: рефакторинг
- test: тесты
- chore: обслуживание

## Безопасность

Перед PR проверь, что не добавил секретов, паролей, захардкоженных TURN-креденшелов, внешних скриптов без SRI.
