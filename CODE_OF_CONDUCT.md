# Contributor Covenant Code of Conduct

Мы обязуемся сделать участие в проекте свободным от притеснений для всех, независимо от возраста, телосложения, инвалидности, этнической принадлежности, половых признаков, гендерной идентичности, уровня опыта, образования, социально-экономического статуса, национальности, внешности, расы, религии, сексуальной идентичности и ориентации.

Неприемлемо: троллинг, оскорбления, преследование, публикация чужой приватной информации, сексуализированные высказывания.

Обратная связь: conduct@vidma.online

Адаптировано из Contributor Covenant 2.1.
