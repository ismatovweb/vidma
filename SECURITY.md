# Security Policy

## Поддерживаемые версии

Только последняя версия main-ветки.

## Как сообщить об уязвимости

Не создавай публичный issue для уязвимостей.

Email: security@vidma.online

Укажи:
- описание уязвимости
- шаги воспроизведения
- влияние
- предлагаемое исправление

Ответ в течение 72 часов.
